# Questboard

Ежедневные и недельные задания для Paper. Каждый игрок получает свой набор из пула в `quests.yml`: сломать, убить, поймать, скрафтить, пройти. Прогресс виден полосой над экраном, награду забирают в меню. Если выполнять все ежедневные задания несколько дней подряд, идёт серия с бонусами.

## Возможности

- `/quests` открывает меню. Задания лежат двумя рядами: ежедневные и недельные. У каждого шкала прогресса, описание и список наград. Готовое задание подсвечивается, клик забирает награду.
- Полоса прогресса вверху экрана показывает одно задание. Закрепить его можно кликом в меню или командой `/quests track <id>`. Без закрепления полоса сама берёт задание, которое ближе всего к концу.
- 5 видов целей: `break` (блоки), `kill` (мобы), `fish` (пойманные предметы), `craft` (созданные предметы), `travel` (пройденные блоки).
- В целях работают id и теги ванильных наборов: `#logs`, `#iron_ores`, `#base_stone_overworld`. Пустой список значит «что угодно».
- Награды: предметы, опыт и команды консоли с `<player>`. Если инвентарь полон, остаток падает под ноги. Деньги выдаются командой экономики: `command: "eco give <player> 250"`.
- Серия: если за день выполнены все ежедневные задания, серия растёт на день, а после пропуска начинается заново. Награды за дни серии задаются в `quests.yml`, после `cycle` дней список начинается снова.
- Ежедневные задания меняются в час из `config.yml` по часовому поясу, который указан там же. Недельные меняются в выбранный день недели.
- Защита от накрутки: блоки, поставленные игроком, не засчитываются при разрушении; молодые культуры не считаются, зрелые считаются; мобы из спавнеров не считаются; в творческом режиме прогресса нет; телепорт не считается пройденным путём.
- Каждая часть выключается в `modules:`, у команды и подкоманд есть алиасы из конфига. Задания, цели, награды и тексты добавляются без правки кода.

## Установка

1. Положите `Questboard-1.0.0.jar` в `plugins/` и запустите сервер.
2. Откройте `plugins/Questboard/quests.yml` и замените задания на свои или оставьте готовые.
3. Зайдите на сервер и напишите `/quests`.

## Как добавить задание

```yaml
quests:
  creeper-sweep:
    period: daily
    goal: kill
    targets: [creeper]
    amount: 5
    icon: GUNPOWDER
    weight: 2
    title: {en: "Creeper sweep", ru: "Зачистка"}
    description: {en: "Defeat 5 creepers.", ru: "Победите 5 криперов."}
    rewards:
      - item: GUNPOWDER
        amount: 8
      - xp: 50
      - command: "eco give <player> 100"
        label: "100 coins"
```

`weight` задаёт частоту выпадения: чем выше число, тем чаще. Новые задания подхватываются командой `/quests reload`, у игроков, которые уже получили набор, остаётся прежний, пока он не сменится.

## Команды

Основная команда — `/quests`, алиасы по умолчанию: `/quest`, `/qb`.

| Команда | Алиасы | Что делает |
|---|---|---|
| `/quests` | | меню заданий |
| `/quests list` | `l` | задания в чате |
| `/quests claim` | `c` | забрать все готовые награды |
| `/quests track <id\|auto\|off>` | `t` | закрепить задание на полосе, вернуть автовыбор или выключить полосу |
| `/quests streak` | `s` | серия дней подряд |
| `/quests help` | `h` | список команд |
| `/quests reload` | `rl` | перечитать конфиг, задания и тексты |
| `/quests reset <игрок>` | | выдать игроку новый набор, серия остаётся |
| `/quests complete <игрок> <id>` | | засчитать игроку задание |

Названия команд из `commands:` подхватываются при запуске сервера, поэтому после смены алиасов нужен перезапуск, а не `reload`.

## Права

| Право | По умолчанию | Что даёт |
|---|---|---|
| `questboard.use` | все | меню, `list`, `claim`, `track`, `streak`, `help` |
| `questboard.admin` | op | всё, включая `reload`, `reset`, `complete` |
| `questboard.command.<подкоманда>` | как у `use` или `admin` | доступ к одной подкоманде |

## Файлы

| Файл | Что в нём |
|---|---|
| `config.yml` | язык, модули, алиасы, время смены, число заданий, защита, звуки |
| `quests.yml` | пул заданий и награды за серию |
| `lang/ru.yml`, `lang/en.yml` | все тексты |

Прогресс игроков хранится в данных самих игроков, отдельной базы нет.

## Совместимость

Paper 26.2, Java 25. Money-плагины напрямую не подключаются, награда деньгами идёт командой. Планировщик Folia не проверялся, поэтому `folia-supported` не включён.
